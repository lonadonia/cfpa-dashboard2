overlay.html?camera=1

In drei Schritten live

  1. Server starten. npm start im Projektordner (oder start-windows.bat / start-mac.command doppelklicken).
  2. OBS: Browserquelle mit http://localhost:8080/overlay.html, 1920 × 1080, über die Kamera legen.
  3. Zoom: In OBS „Virtuelle Kamera starten“ und in Zoom die Kamera „OBS Virtual Camera“ wählen.
